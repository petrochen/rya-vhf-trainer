# Book-First Product & UX Blueprint

Updated: 2026-03-17
Role: `Curriculum Architect + Product/UX Owner`

## Product Positioning

The site should teach strictly through the structure of `RYA VHF SRC Course Handbook 2019`, not as a set of disconnected mini-games.

Target logic:

1. `Book structure -> training blocks`
2. `Training blocks -> measurable readiness`
3. `Readiness -> exam decision`

## UX Structure (Home)

The Home screen is now organised in layers:

1. `Next Recommended Step`
2. `Global progress metrics`
3. `Exam-Critical Block` (what is mandatory for exam pass)
4. `Book-Structured Training Blocks` (chapter-based progression)
5. `Study Flow` (operational order of drills)
6. `Strengths vs Needs Work`
7. `Quick tools`

Additional quick-entry tools on Home:

- `Equipment / Controls`
- `GMDSS Systems`
- `Regulations`

## How “Learned / Not Learned” Is Shown

- Topic readiness:
  - `Not Started`: 0 attempts
  - `In Progress`: attempts exist, but threshold not reached
  - `Strong`: >=8 attempts and >=80% accuracy
- Exam readiness:
  - `Exam-Critical` checklist tracks core exam skills from Appendix-aligned logic.
  - Mock exam checkpoints included (`attempt completed`, `best >=80%`).

## Book-Based Blocks (Implemented)

- `pp. 21-29, 73`: Radio basics + equipment controls + watchkeeping
- `pp. 30-42`: Routine procedure + SMNV
- `pp. 43-54`: Priority calls and escalation logic
- `pp. 61-71`: DSC and follow-up actions
- `pp. 72-77`: Official syllabus consolidation
- `pp. 74-76`: GMDSS systems + SAR (NAVTEX / EPIRB / SART / RCC)
- `p. 77`: Regulations + public correspondence (licence/log/secrecy/AAIC)
- `pp. 78-83`: SMNV + channel selection chart

Each block contains:

- page range
- objective
- status
- direct action (`Start From ...`)

## Product Outcome

The user can now see:

- what to do `now`
- what comes `next`
- what is already `strong`
- what is still `critical` before exam pass

Additionally:

- full topic-tracker coverage now includes not only procedural topics, but also `equipment`, `gmdss`, `regulations`
- the `Exam-Critical` block reflects both practical and theory/regulatory requirements from Appendix 1

This moves the product from “many screens” to “a managed route to exam pass”.
